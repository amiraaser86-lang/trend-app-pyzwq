# و ادخل الوصف تضبيق  وم

> منصّة واحدة لإدارة فرقك عن بُعد بوضوح تام.

تم توليد هذا المشروع بواسطة **Trend app builder** من وصف نصّي.

## التشغيل
افتح `index.html` مباشرة، أو شغّل:

```bash
npx serve .
```

## البنية
- `index.html` — الصفحة الرئيسية
- `assets/css/style.css` — الأنماط
- `assets/js/data.js` — بيانات التطبيق
- `assets/js/app.js` — منطق التطبيق
- `data/content.json` — مصدر البيانات الخام
